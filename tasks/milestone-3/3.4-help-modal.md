# Task 3.4: Help Modal

**Milestone**: 3 - Keyboard Navigation
**Status**: Todo
**Dependencies**: 3.1 Keyboard Hook
**Blocks**: None

## Goal

Show keyboard shortcuts overlay when user presses `?`.

## Context

- Common pattern in keyboard-driven apps
- Should list all available shortcuts
- Dismiss with Escape or clicking outside

## Requirements

### 1. Help Modal Component (`src/components/keyboard-help.tsx`)

```typescript
export function KeyboardHelp({ open, onClose }) {
  const shortcuts = [
    { key: "j / ↓", action: "Next email" },
    { key: "k / ↑", action: "Previous email" },
    { key: "Enter / o", action: "Open email" },
    { key: "Escape / u", action: "Back to inbox" },
    { key: "g i", action: "Go to inbox" },
    { key: "r", action: "Refresh" },
    { key: "?", action: "Show shortcuts" },
  ];

  // Render modal with shortcuts table
}
```

### 2. Modal Styling

- Centered overlay
- Semi-transparent backdrop
- Clean, readable layout
- Use shadcn Dialog if available

### 3. Trigger

- `?` key opens modal
- Escape or click outside closes
- Add to global keyboard handlers

## Acceptance Criteria

- [ ] `?` opens help modal
- [ ] All shortcuts listed
- [ ] Modal closes with Escape
- [ ] Modal closes clicking outside
- [ ] Clean, readable design
