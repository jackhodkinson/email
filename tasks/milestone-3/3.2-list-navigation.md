# Task 3.2: List Navigation

**Milestone**: 3 - Keyboard Navigation
**Status**: Todo
**Dependencies**: 3.1 Keyboard Hook
**Blocks**: None

## Goal

Navigate the email list using arrow keys and open with `Enter`.

## Context

- Arrow Up/Down for navigation
- `Enter` opens selected email

## Requirements

### 1. Selection State

- Track currently selected email index
- Visual highlight for selected item
- Auto-scroll to keep selection visible

### 2. Keyboard Handlers

```typescript
// In inbox page
const [selectedIndex, setSelectedIndex] = useState(0);

useKeyboard({
  ArrowDown: () => selectNext(),
  ArrowUp: () => selectPrevious(),
  Enter: () => openSelected(),
});
```

### 3. Scroll Into View

- When selection moves off-screen, scroll to show it
- Use `scrollIntoView({ block: "nearest" })`

## Acceptance Criteria

- [ ] j/k moves selection down/up
- [ ] Arrow keys also work
- [ ] Enter/o opens selected email
- [ ] Selection wraps or stops at bounds
- [ ] Selected item always visible
- [ ] Visual indicator clear
