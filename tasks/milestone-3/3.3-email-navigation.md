# Task 3.3: Email View Navigation

**Milestone**: 3 - Keyboard Navigation
**Status**: Todo
**Dependencies**: 3.1 Keyboard Hook
**Blocks**: None

## Goal

Navigate back to inbox from email view using `Escape` or `u`.

## Context

- `Escape` = back (common convention)
- `u` = back (Gmail convention)
- `g i` = go to inbox (from anywhere)

## Requirements

### 1. Email View Shortcuts

```typescript
// In email view
useKeyboard({
  Escape: () => goToInbox(),
  u: () => goToInbox(),
});
```

### 2. Global "Go To" Shortcuts

- `g i` sequence goes to inbox from anywhere
- Implement in root layout or keyboard hook

### 3. Integration

- Works on email detail page
- Uses router navigation

## Acceptance Criteria

- [ ] Escape closes email, returns to inbox
- [ ] `u` also returns to inbox
- [ ] `g i` works from any page
- [ ] Maintains expected behavior
