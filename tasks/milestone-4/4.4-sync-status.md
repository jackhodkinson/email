# Task 4.4: Sync Status UI

**Milestone**: 4 - Smart Sync
**Status**: Todo
**Dependencies**: 4.1 Delta Sync
**Blocks**: None

## Goal

Show visual indicator of sync status (syncing, synced, error).

## Context

- Users should know when sync is happening
- Show last sync time
- Indicate errors clearly

## Requirements

### 1. Sync State

Track sync status in state/context:
```typescript
type SyncStatus = "idle" | "syncing" | "error";

interface SyncState {
  status: SyncStatus;
  lastSyncTime: Date | null;
  error: string | null;
}
```

### 2. Status Indicator Component

- Show in header or status bar
- "Syncing..." with spinner
- "Last synced: 2 minutes ago"
- Error state with retry option

### 3. Integration

- Update status when sync starts/completes
- Persist last sync time
- Clear errors on successful sync

## Acceptance Criteria

- [ ] Shows "Syncing" during sync
- [ ] Shows last sync time when idle
- [ ] Shows error state on failure
- [ ] Status updates in real-time
- [ ] Unobtrusive but visible
