# Task 4.2: Periodic Sync

**Milestone**: 4 - Smart Sync
**Status**: Todo
**Dependencies**: 4.1 Delta Sync
**Blocks**: None

## Goal

Automatically sync emails every 60 seconds while the app is open.

## Context

- User expects new emails to appear without manual action
- Delta sync is efficient enough for frequent polling
- Future: replace with push notifications

## Requirements

### 1. Polling Hook (`src/lib/hooks/use-sync.ts`)

```typescript
export function usePeriodicSync(accountId: string, intervalMs = 60000) {
  useEffect(() => {
    const interval = setInterval(async () => {
      await syncAccount({ data: { accountId } });
    }, intervalMs);

    return () => clearInterval(interval);
  }, [accountId, intervalMs]);
}
```

### 2. Integration

- Start polling when app loads with authenticated account
- Stop when app unmounts or loses focus (optional optimization)
- Restart on account switch

### 3. Refresh UI

- After sync, refresh email list
- Use TanStack Router's `invalidate` or React Query

## Acceptance Criteria

- [ ] Sync runs every 60 seconds
- [ ] New emails appear without refresh
- [ ] No duplicate syncs running
- [ ] Polling stops when app closes
- [ ] Works across account switches
