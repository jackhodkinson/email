# Task 4.3: Manual Refresh

**Milestone**: 4 - Smart Sync
**Status**: Todo
**Dependencies**: 4.1 Delta Sync
**Blocks**: None

## Goal

Allow users to manually trigger sync via `r` key or UI button.

## Context

- Sometimes users want immediate refresh
- Keyboard shortcut `r` for quick access
- Also provide clickable button

## Requirements

### 1. Keyboard Shortcut

Add `r` to keyboard handlers:
```typescript
useKeyboard({
  r: () => triggerSync(),
});
```

### 2. UI Button

- Refresh icon in header
- Shows spinner during sync
- Disabled while syncing

### 3. Sync Logic

- Call delta sync
- Show loading state
- Refresh email list on completion
- Handle errors gracefully

## Acceptance Criteria

- [ ] `r` key triggers sync
- [ ] Refresh button visible in UI
- [ ] Loading indicator during sync
- [ ] Email list updates after sync
- [ ] Can't trigger multiple concurrent syncs
