## Goal

Implement incremental sync using Gmail's History API to fetch only changes since last sync.

## Context

- Initial sync stores `historyId` (Task 1.6)
- History API returns changes since that ID
- Much more efficient than full sync
- See [ARCHITECTURE.md](../../ARCHITECTURE.md#gmail-sync-strategy)

### 3. Smart Sync Selection

```typescript
export async function syncAccount(account: Account) {
  if (!account.history_id) {
    return performInitialSync(account);
  }
  return performDeltaSync(account);
}
```
