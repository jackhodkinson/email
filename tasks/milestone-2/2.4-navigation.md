# Task 2.4: Navigation Flow

**Milestone**: 2 - Read an Email
**Status**: Todo
**Dependencies**: 2.1 Email Detail Route, 2.2 HTML Rendering
**Blocks**: Milestone 3

## Goal

Implement smooth navigation between inbox and email view.

## Context

- TanStack Router handles routing
- Need click handlers in email list
- Need back navigation from email view

## Requirements

### 1. Email List Click Navigation

- Clicking email item navigates to `/email/[id]`
- Use TanStack Router's `useNavigate` or `Link`

### 2. Back Navigation

- Back button in email view header
- Returns to inbox
- Preserve scroll position if possible

### 3. URL Structure

- `/` - Inbox
- `/email/$id` - Single email

### 4. Loading States

- Show loading during navigation
- Consider optimistic UI

## Acceptance Criteria

- [ ] Click email → navigate to detail view
- [ ] Back button → return to inbox
- [ ] Browser back/forward work correctly
- [ ] Deep linking works (refresh on email page)
- [ ] Smooth transitions
