# Task 2.1: Email Detail Route

**Milestone**: 2 - Read an Email
**Status**: Todo
**Dependencies**: Milestone 1 complete
**Blocks**: 2.2 HTML Rendering, 2.3 Attachments, 2.4 Navigation

## Goal

Create a route to display a single email's full content.

## Context

- Using TanStack Router file-based routing
- Route: `/email/$id` where `$id` is the Gmail message ID
- Email data already in SQLite from Milestone 1

## Requirements

### 1. Create Route (`src/routes/email.$id.tsx`)

- Dynamic route parameter `$id`
- Loader fetches email by ID from database
- Display: sender, recipients, date, subject, body

### 2. Server Function

```typescript
export const getEmailById = createServerFn({ method: "GET" })
  .validator((data: { id: string }) => data)
  .handler(async ({ data }) => {
    const email = await getEmailById(data.id);
    if (!email) throw new Error("Email not found");
    return email;
  });
```
