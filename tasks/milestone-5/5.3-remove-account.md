# Task 5.3: Remove Account

**Milestone**: 5 - Multiple Accounts
**Status**: Todo
**Dependencies**: 5.1 Account List
**Blocks**: None

## Goal

Allow users to disconnect a Gmail account.

## Context

- Should remove account and all its cached emails
- Use database transaction for consistency
- Require confirmation before deletion

## Requirements

### 1. Server Function

```typescript
export const removeAccount = createServerFn({ method: "POST" })
  .validator((data: { accountId: string }) => data)
  .handler(async ({ data }) => {
    await db.begin(async (tx) => {
      // Delete attachments for this account's emails
      await tx`DELETE FROM attachments WHERE email_id IN (
        SELECT id FROM emails WHERE account_id = ${data.accountId}
      )`;
      // Delete emails
      await tx`DELETE FROM emails WHERE account_id = ${data.accountId}`;
      // Delete account
      await tx`DELETE FROM accounts WHERE id = ${data.accountId}`;
    });
    return { success: true };
  });
```

### 2. UI for Removal

- Remove button in account list
- Confirmation dialog
- Show account email being removed

### 3. Post-Removal Behavior

- If removing current account, switch to another
- If no accounts left, show "Add Account" screen

## Acceptance Criteria

- [ ] Can remove any connected account
- [ ] Confirmation required
- [ ] All associated data deleted
- [ ] UI updates appropriately
- [ ] Handles "last account" case
