# Task 5.4: Per-Account Sync

**Milestone**: 5 - Multiple Accounts
**Status**: Todo
**Dependencies**: 5.1 Account List, Milestone 4
**Blocks**: None

## Goal

Each account syncs independently with its own schedule and state.

## Context

- Multiple accounts = multiple sync loops
- Each has own historyId
- Should sync in background without blocking UI

## Requirements

### 1. Multi-Account Sync Manager

```typescript
export function useMultiAccountSync(accounts: Account[]) {
  useEffect(() => {
    // Start sync interval for each account
    const intervals = accounts.map(account => {
      return setInterval(() => {
        syncAccount({ data: { accountId: account.id } });
      }, 60000);
    });

    // Initial sync for all accounts
    accounts.forEach(account => {
      syncAccount({ data: { accountId: account.id } });
    });

    return () => intervals.forEach(clearInterval);
  }, [accounts]);
}
```

### 2. Per-Account Status

- Track sync status per account
- Show indicator per account (optional)
- Errors isolated per account

### 3. Sync on Account Add

- Trigger initial sync when new account added
- Don't block other accounts

## Acceptance Criteria

- [ ] Each account syncs on its own schedule
- [ ] New account triggers immediate sync
- [ ] Sync errors don't affect other accounts
- [ ] Status tracked per account
- [ ] UI remains responsive
