# Task 5.1: Account List

**Milestone**: 5 - Multiple Accounts
**Status**: Todo
**Dependencies**: Milestone 1 complete
**Blocks**: 5.2, 5.3, 5.4

## Goal

Display all connected Gmail accounts in the UI.

## Context

- Database already supports multiple accounts
- Need UI to show and manage them
- Foundation for account switching

## Requirements

### 1. Server Function

```typescript
export const getAccounts = createServerFn({ method: "GET" })
  .handler(async () => {
    const accounts = await getAllAccounts();
    // Return without sensitive tokens
    return accounts.map(a => ({
      id: a.id,
      email: a.email,
    }));
  });
```

### 2. Account List Component

- Show email address for each account
- Visual indicator for currently active account
- "Add Account" button

### 3. Integration Points

- Header area account display
- Settings/accounts page (optional)

## Acceptance Criteria

- [ ] All accounts displayed
- [ ] Current account highlighted
- [ ] Add Account button works
- [ ] Tokens not exposed to client
