# Task 1.1: Database Setup

**Milestone**: 1 - Foundation
**Status**: Todo
**Dependencies**: None
**Blocks**: 1.3 OAuth Flow, 1.6 Initial Sync

## Goal

Set up SQLite database with schema for accounts, emails, and attachments using Bun's native SQL API.

## Context

- See [ARCHITECTURE.md](../../ARCHITECTURE.md#database-schema) for the full schema
- Using Bun's native `bun:sql` API (no npm packages needed for SQLite)
- Database stored at `data/email.db`
- This is foundational - OAuth and sync depend on this being complete

## Requirements

### 1. Database Client (`src/lib/db/client.ts`)

Create a database connection module:

```typescript
import { SQL } from "bun";

// Create/open database
const db = new SQL("sqlite://data/email.db");

// Configure for performance and safety
// - WAL mode for better concurrent reads
// - Foreign keys enabled

export { db };
```

### 2. Schema Initialization (`src/lib/db/schema.ts`)

Create a script that initializes the database schema:

- `accounts` table - OAuth tokens for Gmail accounts
- `emails` table - Cached email data
- `attachments` table - Attachment metadata
- All indexes from ARCHITECTURE.md

This should be idempotent (safe to run multiple times).

### 3. Query Helpers (`src/lib/db/queries.ts`)

Create typed query functions (minimal set for now):


## Technical Notes

### Bun SQL API

```typescript
import { SQL } from "bun";

const db = new SQL("sqlite://data/email.db");

// Tagged templates auto-escape parameters (SQL injection safe)
const emails = await db`SELECT * FROM emails WHERE account_id = ${accountId}`;

// Insert with object
await db`INSERT INTO emails ${db({ id, subject, sender })}`;

// Transactions
await db.begin(async (tx) => {
  await tx`DELETE FROM emails WHERE account_id = ${accountId}`;
  await tx`DELETE FROM accounts WHERE id = ${accountId}`;
});
```

### Schema Notes

- Use `TEXT` for IDs (Gmail IDs are strings)
- Use `INTEGER` for timestamps (Unix epoch)
- Store JSON arrays as `TEXT` (labels, recipients)
- `history_id` on accounts is for delta sync (Task 1.6)

### Directory Creation

The `data/` directory may not exist. Create it if needed:

```typescript
import { mkdir } from "fs/promises";
await mkdir("data", { recursive: true });
```
