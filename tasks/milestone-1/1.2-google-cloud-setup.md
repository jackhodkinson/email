# Task 1.2: Google Cloud Setup

**Milestone**: 1 - Foundation
**Status**: Todo
**Dependencies**: None
**Blocks**: 1.3 OAuth Flow, 1.4 Gmail API Client

## Goal

Create a Google Cloud project with Gmail API enabled and OAuth 2.0 credentials configured.

## Context

This is a **manual setup task** - no code to write. The output is credentials that will be used in Tasks 1.3 and 1.4.

## Requirements

### 1. Create Google Cloud Project

1. Go to [Google Cloud Console](https://console.cloud.google.com/)
2. Create a new project (e.g., "Email Client Dev")
3. Note the Project ID

### 2. Enable Gmail API

1. Go to **APIs & Services > Library**
2. Search for "Gmail API"
3. Click **Enable**

### 3. Configure OAuth Consent Screen

1. Go to **APIs & Services > OAuth consent screen**
2. Choose **External** user type (for development)
3. Fill in required fields:
   - App name: "Email Client"
   - User support email: your email
   - Developer contact: your email
4. Add scopes:
   - `https://www.googleapis.com/auth/gmail.readonly`
5. Add test users (your Gmail addresses)
6. Save

### 4. Create OAuth Credentials

1. Go to **APIs & Services > Credentials**
2. Click **Create Credentials > OAuth client ID**
3. Application type: **Web application**
4. Name: "Email Client Web"
5. Authorized redirect URIs:
   - `http://localhost:3000/auth/callback`
6. Click **Create**
7. Download the JSON or copy Client ID and Client Secret

### 5. Store Credentials

Create `email-app/.env.local` (gitignored):

```env
GOOGLE_CLIENT_ID=your-client-id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=your-client-secret
GOOGLE_REDIRECT_URI=http://localhost:3000/auth/callback
```

### 6. Ensure .env.local is Gitignored

Verify `.gitignore` includes:
```
.env.local
.env*.local
```

## Technical Notes

### Why "External" User Type?

For development, External with test users is simpler than setting up a Google Workspace org. The app will show "unverified" warnings, which is fine for local development.

### OAuth Scopes

For MVP (read-only):
- `https://www.googleapis.com/auth/gmail.readonly`

Post-MVP (when adding actions):
- `https://www.googleapis.com/auth/gmail.modify`

### Redirect URI

Must exactly match what's configured in Google Cloud:
- Protocol: `http` (not https for localhost)
- Port: `3000` (TanStack Start default)
- Path: `/auth/callback` (we'll create this route in Task 1.3)

## Troubleshooting

### "Access blocked: This app's request is invalid"
- Check redirect URI matches exactly
- Ensure you're using a test user email

### "This app isn't verified"
- Normal for development
- Click "Advanced" > "Go to Email Client (unsafe)"
- Only works for test users you've added
