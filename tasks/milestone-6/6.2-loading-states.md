# Task 6.2: Loading States

**Milestone**: 6 - Polish & Robustness
**Status**: Todo
**Dependencies**: Milestones 1-5
**Blocks**: None

## Goal

Show appropriate loading indicators during all async operations.

## Context

- SSR provides initial data, but client navigation needs loading states
- Sync operations need feedback
- Avoid layout shift

## Requirements

### 1. Loading Scenarios

| Scenario | Solution |
|----------|----------|
| Initial page load | SSR (no spinner needed) |
| Navigation to email | Skeleton or spinner |
| Sync in progress | Header indicator |
| Account switch | List skeleton |
| Attachment download | Button spinner |

### 2. Skeleton Components

Create skeletons for:
- Email list item
- Email content view
- Account picker

### 3. Integration

- Use TanStack Router's pending states
- Use React Suspense where appropriate
- Keep skeletons same size as content (no layout shift)

## Acceptance Criteria

- [ ] No blank screens during loading
- [ ] Skeletons match final content size
- [ ] Loading indicators for async actions
- [ ] Smooth transitions
- [ ] No layout shift
