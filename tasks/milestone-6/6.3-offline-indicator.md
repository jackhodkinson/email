# Task 6.3: Offline Indicator

**Milestone**: 6 - Polish & Robustness
**Status**: Todo
**Dependencies**: Milestone 1
**Blocks**: None

## Goal

Show clear indicator when Gmail API is unreachable.

## Context

- App works offline with cached data
- User should know they're viewing cached data
- Different from sync status (sync can fail while online)

## Requirements

### 1. Online Detection

```typescript
export function useOnlineStatus() {
  const [isOnline, setIsOnline] = useState(navigator.onLine);

  useEffect(() => {
    const handleOnline = () => setIsOnline(true);
    const handleOffline = () => setIsOnline(false);

    window.addEventListener("online", handleOnline);
    window.addEventListener("offline", handleOffline);

    return () => {
      window.removeEventListener("online", handleOnline);
      window.removeEventListener("offline", handleOffline);
    };
  }, []);

  return isOnline;
}
```

### 2. Offline Banner

- Show banner when offline
- "You're offline. Viewing cached emails."
- Unobtrusive but visible
- Dismiss or auto-hide when online

### 3. Behavior When Offline

- Disable sync button
- Disable "Add Account" (requires OAuth)
- Show cached emails normally
- Queue actions if any (future)

## Acceptance Criteria

- [ ] Offline detected via browser API
- [ ] Clear offline indicator shown
- [ ] Cached emails still viewable
- [ ] Actions disabled appropriately
- [ ] Indicator clears when back online
